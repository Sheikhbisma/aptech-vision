Character Entities

This example demonstrates how to use HTML character entities. Some symbols cannot be typed directly in HTML (like < or >) because the browser may confuse them with tags. So we use entities: &lt; displays the less-than symbol (<), &gt; displays the greater-than symbol (>), &copy; shows the copyright symbol (©), and &reg; shows the registered trademark symbol (®). Character entities are useful when you need to display reserved characters or special symbols. 

<p>Less than: &lt; </p>
<p>Greater than: &gt; </p>
<p>Copyright: &copy; 2025</p>
<p>Registered: &reg;</p>

How To link CSS

Internal Link

Internal CSS is written inside the <style> tag in the HTML <head>. It lets you style elements on the same page. Here, the background color is light blue, headings are dark blue, and paragraphs are dark green.

<!DOCTYPE html>
<html>
<head>
    <style>
        body {
            background-color: lightblue;
            font-family: Arial, sans-serif;
        }
        h1 {
            color: darkblue;
        }
        p {
            color: darkgreen;
        }
    </style>
</head>
<body>
    <h1>Hello CSS!</h1>
    <p>This is a paragraph with internal CSS.</p>
</body>
</html>

External CSS (using .css file)

External CSS is written in a separate .css file and linked using <link>. This is useful for styling multiple pages consistently.

<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <h1>Hello External CSS!</h1>
    <p>This paragraph is styled using an external CSS file.</p>
</body>
</html>

Flex Properties

Flexbox is used to create flexible layouts. display flex makes a container arrange its child elements in a single line (row) by default, allowing easy horizontal alignment, spacing, and responsive layout. Parent container properties control overall layout (direction, alignment, wrapping). Child item properties control individual item behavior (growth, shrink, order, self-alignment). Using flexbox makes horizontal & vertical alignment easy, responsive layouts simpler, and spacing consistent.

<!-- Flex Container (Parent) Properties -->
.container {
    display: flex;             /* makes the container a flexbox */
    flex-direction: row;       /* row | column | row-reverse | column-reverse */
    justify-content: flex-start; /* flex-start|flex-end|center|space-between|space-around|space-evenly */
    align-items: stretch;      /* flex-start | flex-end | center | baseline | stretch */
    flex-wrap: nowrap;         /* nowrap | wrap | wrap-reverse */
    align-content: stretch;    /* for multi-line flex containers */
}

<!-- Flex Item (Child) Properties -->
.item {
    flex-grow: 0;             /* number, how much item grows relative to others */
    flex-shrink: 1;           /* number, how much item shrinks if needed */
    flex-basis: auto;         /* initial size of item */
    order: 0;                 /* number, changes order of items */
    align-self: auto;         /* overrides align-items for this item */
}

Height And Width

In CSS, width sets the horizontal size of an element, and height sets the vertical size. You can use units like px (pixels), % (percentage of parent), em, rem, and more.

    height: 150px;         /* vertical size */

    border: 2px solid navy;
    margin: 10px;

You can also use percentages: width: 50% makes the element half the width of its parent container.

Styling For List

The CSS property list-style-type controls the appearance of these bullets or numbers. For unordered lists, possible values include disc (default), circle, square, or none. For ordered lists, values like decimal, upper-roman, lower-alpha can be used. This allows you to customize how list items appear visually.

<style>
ul {

}
ol {
    list-style-type: upper-roman; /* numbers appear as I, II, III... */
}

Anchor (a) Tag Decoration

Using the CSS property text-decoration, you can control this line style. For example, none removes the underline, underline adds it, overline places a line above the text, and line-through strikes through the text. You can also style the link color separately using the color property.

<style>
a {

}

Grid system

CSS Grid allows you to divide a container into rows and columns. Using grid-template-columns, you define how many columns the grid will have and their width. grid-gap adds space between grid items. Each child element inside the grid container automatically becomes a grid item and aligns itself in the defined rows and columns. Grid is very powerful for creating layouts like galleries, dashboards, and multi-column designs. 


.container {
    display: grid;
    grid-template-columns: 100px 100px 100px; /* 3 columns, each 100px wide */
    grid-template-columns:repeat(3,1fr)/*it means 3 equal columns*/
    grid-gap: 10px;
}

Positions

CSS positioning allows you to control **where an element appears** on a web page. The main property is position, which can take several values to change the element's placement. - relative moves the element slightly from its normal position. - absolute positions the element relative to its nearest parent with a position set. - fixed keeps the element in place even when scrolling. - sticky sticks the element to a specified point when scrolling past it. You can combine these with top, right, bottom, and left to adjust the exact position.

<style>
.container {
    position: relative; /* parent should be positioned */
    width: 300px;
    height: 200px;
    background-color: lightgray;
}
.box {
    position: absolute; /* absolute positioning */
    top: 20px;
    left: 50px;
    width: 100px;
    height: 80px;
    background-color: lightcoral;
    text-align: center;
    line-height: 80px;
}
</style>

: :before And : :after

CSS ::before and ::after are pseudo-elements used to insert content **before or after an element's actual content**. They are often used for decorative purposes, icons, or adding text without changing HTML. The content property defines what will be added. These pseudo-elements are useful for adding decorative symbols, quotes, or small icons without modifying the HTML structure. You can style them with color, font-size, margin, or any CSS property. 

<style>
h3::before {
    content: "★ "; /* adds a star before the heading text */
    color: gold;
}
h3::after {
    content: " ☆"; /* adds a star after the heading text */
    color: gold;
}
</style>

:Hover Effect

The :hover pseudo-class applies styles when the user hovers the mouse over an element. In this example, the link has no underline by default and is blue in color. When hovered, the link becomes underlined and changes its color to red. Hover effects are widely used to give visual feedback and improve user experience on web pages. 

<style>
a {
    text-decoration: none;
    color: blue;
}
a:hover {
    text-decoration: underline; /* underline appears when hovered */
    color: red; /* color changes on hover */
}
</style>

<a href="https://www.google.com">Go to Google</a>

Transition

The transition property makes changes in CSS properties smooth over time. In this example, when the button is hovered, the background color changes from blue to green and the button slightly grows in size. The 0.5s and 0.3s define the duration of the transitions, and ease controls the speed curve. Without transition, the color and size would change instantly, but with it, the changes are gradual and visually appealing. 

a{
  transition: property duration timing-function delay;
  transition: all 0.3s ease; /* all properties change smoothly in 0.3s */
}

Transform

The transform property in CSS allows you to visually change an element without affecting the layout around it

translate(x, y)

Moves the element horizontally (x) and vertically (y).

transform: translate(50px, 20px); /* moves right 50px, down 20px */

rotate(angle)

Rotates the element by a given angle.

transform: rotate(45deg); /* rotates element 45 degrees clockwise */

scale(factor)

Scales (resizes) element uniformly.

transform: scale(1.5); /* 1.5 times bigger */

Animation

CSS animations allow you to **move, change, or transform elements smoothly over time** without using JavaScript. Animations are defined using @keyframes to describe the sequence of changes and the animation property to apply it to elements.In this example, the box moves horizontally from left to right and changes color. The animation property applies the animation to the element, specifying the name (moveBox), duration (3 seconds), and repetition (infinite). CSS animations make web pages more interactive and visually appealing without using JavaScript.

<style>
  animation-name → name of @keyframes
animation-duration → how long the animation lasts
animation-iteration-count → how many times to repeat
animation-timing-function → speed curve (linear, ease, ease-in-out)
@keyframes moveBox {
    0%   { transform: translateX(0); background-color: lightblue; }
    50%  { transform: translateX(100px); background-color: lightgreen; }
    100% { transform: translateX(0); background-color: lightblue; }
}

.box {
    width: 100px;
    height: 100px;
    background-color: lightblue;
    margin: 50px;
    animation: moveBox 3s infinite; /* name duration repeat */
}
</style>

<div class="box">Animated Box</div>
