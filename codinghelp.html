Ordered List(ol)

Link With Attributes

This example shows how to create different types of links in HTML. The first link opens Google in a new browser tab using target="_blank". The second link is a mail link that opens the default email application to send an email. The third link is a telephone link that allows the user to directly call the given number from devices that support calling, like mobile phones. 

<h3>Links Example</h3>
<a href="https://www.google.com" target="_blank">Open Google in new tab</a>
<br>
<a href="mailto:example@email.com">Send Email</a>
<br>
<a href="tel:+123456789">Call Us</a>

Character Entities

This example demonstrates how to use HTML character entities. Some symbols cannot be typed directly in HTML (like < or >) because the browser may confuse them with tags. So we use entities: &lt; displays the less-than symbol (<), &gt; displays the greater-than symbol (>), &copy; shows the copyright symbol (©), and &reg; shows the registered trademark symbol (®). Character entities are useful when you need to display reserved characters or special symbols. 

<p>Less than: &lt; </p>
<p>Greater than: &gt; </p>
<p>Copyright: &copy; 2025</p>
<p>Registered: &reg;</p>

Audio

The <audio> tag is used to add sound or music to a webpage, and it usually includes the controls attribute so the user can play, pause, or adjust volume. 

<audio controls>
    <source src="audiofile.mp3" type="audio/mpeg">
    Your browser does not support the audio element.
</audio>

Video

The <video> tag is used to embed videos, also with the controls attribute so the user can play, pause, or resize the video. 

<video controls width="320" height="240">
    <source src="videofile.mp4" type="video/mp4">
    Your browser does not support the video tag.
</video>

How To link CSS

Internal Link

Internal CSS is written inside the <style> tag in the HTML <head>. It lets you style elements on the same page. Here, the background color is light blue, headings are dark blue, and paragraphs are dark green.

<!DOCTYPE html>
<html>
<head>
    <style>
        body {
            background-color: lightblue;
            font-family: Arial, sans-serif;
        }
        h1 {
            color: darkblue;
        }
        p {
            color: darkgreen;
        }
    </style>
</head>
<body>
    <h1>Hello CSS!</h1>
    <p>This is a paragraph with internal CSS.</p>
</body>
</html>

External CSS (using .css file)

External CSS is written in a separate .css file and linked using <link>. This is useful for styling multiple pages consistently.

<!DOCTYPE html>
<html>
<head>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <h1>Hello External CSS!</h1>
    <p>This paragraph is styled using an external CSS file.</p>
</body>
</html>

Inline Css

Inline CSS is written directly inside the HTML element using the style attribute. It is useful for quick changes but not recommended for large projects.

<h1 style="color: purple; text-align: center;">Hello Inline CSS!</h1>
<p style="color: teal; font-size: 18px;">This paragraph uses inline CSS.</p>
