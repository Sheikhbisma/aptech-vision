Flex Properties

Flexbox is used to create flexible layouts. display flex makes a container arrange its child elements in a single line (row) by default, allowing easy horizontal alignment, spacing, and responsive layout. Parent container properties control overall layout (direction, alignment, wrapping). Child item properties control individual item behavior (growth, shrink, order, self-alignment). Using flexbox makes horizontal & vertical alignment easy, responsive layouts simpler, and spacing consistent. 

<!-- Flex Container (Parent) Properties -->
.container {
    display: flex;             /* makes the container a flexbox */
    flex-direction: row;       /* row | column | row-reverse | column-reverse */
    justify-content: flex-start; /* flex-start|flex-end|center|space-between|space-around|space-evenly */
    align-items: stretch;      /* flex-start | flex-end | center | baseline | stretch */
    flex-wrap: nowrap;         /* nowrap | wrap | wrap-reverse */
    align-content: stretch;    /* for multi-line flex containers */
}

<!-- Flex Item (Child) Properties -->
.item {
    flex-grow: 0;             /* number, how much item grows relative to others */
    flex-shrink: 1;           /* number, how much item shrinks if needed */
    flex-basis: auto;         /* initial size of item */
    order: 0;                 /* number, changes order of items */
    align-self: auto;         /* overrides align-items for this item */
}

Grid system

CSS Grid allows you to divide a container into rows and columns. Using grid-template-columns, you define how many columns the grid will have and their width. grid-gap adds space between grid items. Each child element inside the grid container automatically becomes a grid item and aligns itself in the defined rows and columns. Grid is very powerful for creating layouts like galleries, dashboards, and multi-column designs. 


.container {
    display: grid;
    grid-template-columns: 100px 100px 100px; /* 3 columns, each 100px wide */
    grid-template-columns:repeat(3,1fr)/*it means 3 equal columns*/
    grid-gap: 10px;
}

JavaScript Variables

In JavaScript, variables are used to store data values. You can think of them as containers that hold information. There are three main ways to declare variables: var, let, and const.

// Using var (old way, function scoped)
var name = "Ali";

// Using let (modern way, block scoped)
let age = 20;

// Using const (cannot be changed once assigned)
const country = "Pakistan";

console.log(name);     // Output: Ali
console.log(age);      // Output: 20
console.log(country);  // Output: Pakistan


- var: Old keyword, function-scoped, not recommended for modern coding.  
- let: Best choice for variables that can change.  
- const: Use when you don’t want the value to change.

JavaScript Data Types

In JavaScript, data types define the kind of values a variable can hold. They are divided into two categories: Primitive and Non-Primitive.

1. Primitive Data Types


Primitive data types are the basic building blocks of JavaScript. They include:


// String → Text data
let name = "Ali";

// Number → Numeric values
let age = 20;

// Boolean → True or False
let isStudent = true;

// Undefined → Variable declared but not assigned
let city;
console.log(city); // Output: undefined

// Null → Empty value
let car = null;

// Symbol → Unique identifier (advanced use)
let sym = Symbol("id");

// BigInt → Very large numbers
let bigNumber = 123456789012345678901234567890n;

2. Non-Primitive (Reference) Data Types


Non-primitive types store collections of values or more complex entities. They include:


// Object → Collection of key-value pairs
let person = {
  name: "Sara",
  age: 22
};

// Array → List of values
let fruits = ["Apple", "Banana", "Mango"];

JavaScript Operators

Operators are special symbols used to perform operations on values and variables. Example: + is used to add numbers, * is used to multiply.

1. Arithmetic Operators

Used for mathematical calculations.

let a = 10, b = 3;

console.log(a + b);  // Addition → 13
console.log(a - b);  // Subtraction → 7
console.log(a * b);  // Multiplication → 30
console.log(a / b);  // Division → 3.333...
console.log(a % b);  // Modulus (remainder) → 1
console.log(a ** b); // Exponentiation (power) → 1000

2. Assignment Operators

Used to assign values to variables.

let x = 5;
x += 3;  // Same as x = x + 3 → 8
x -= 2;  // Same as x = x - 2 → 6
x *= 4;  // Same as x = x * 4 → 24
x /= 6;  // Same as x = x / 6 → 4

3. Comparison Operators

Used to compare values (result is true or false).

console.log(5 == "5");   // true (only checks value)
console.log(5 === "5");  // false (checks value + type)
console.log(10 != 5);    // true (! => not means 10 is not equal to 5)
console.log(10 > 6);     // true
console.log(10 < 6);     // false
console.log(10 >= 10);   // true

4. Logical Operators

Used to combine conditions.

let age = 20;

console.log(age > 18 && age < 30); // AND → true
console.log(age > 25 || age < 18); // OR → false
console.log(!(age > 18));          // NOT → false

5. String Operators

Used to join (concatenate) strings.

let firstName = "Ali";
let lastName = "Khan";

console.log(firstName + " " + lastName);  // Output: Ali Khan
Summary:  
- Arithmetic → +, -, *, /, %, **  
- Assignment → =, +=, -=, *=, /=  
- Comparison → ==, ===, !=, >, <, >=, <=  
- Logical → &&, ||, !  
- String → + (concatenation)

Getting Elements in JavaScript

To interact with HTML using JavaScript, we first need to "select" or "get" the element. JavaScript provides different methods to do this:

1. getElementById()

Selects an element by its id.
// HTML
  <p id="demo">Hello</p>
// JavaScript
let element = document.getElementById("demo");
console.log(element.innerText);  // Output: Hello

2. getElementsByClassName()

Selects all elements with a given class. (It returns a list).

// HTML
< p class="text"> First</p>
< p class="text"> Second</p>

// JavaScript
let items = document.getElementsByClassName("text");
console.log(items[0].innerText); // Output: First [0] is the index number

3. getElementsByTagName()

Selects all elements with a given tag name.

// HTML
<h1>Heading 1</h1>
<h1>Heading 2</h1>
// JavaScript
let headings = document.getElementsByTagName("h1");
console.log(headings[1].innerText); // Output: Heading 2

4. querySelector()

Selects the first element that matches a CSS selector.

// HTML
<p class="text"> Hello</p>
// JavaScript
let element = document.querySelector(".text");
console.log(element.innerText);  // Output: Hello

5. querySelectorAll()

Selects all elements that match a CSS selector.

// HTML
<p class="text"> one</p>
<p class="text"> two</p>

// JavaScript
let elements = document.querySelectorAll(".text");
console.log(elements[0].innerText); // Output: One
console.log(elements[1].innerText); // Output: Two


Summary:  
- getElementById() → Single element by ID.  
- getElementsByClassName() → List of elements by class.  
- getElementsByTagName() → List of elements by tag.  
- querySelector() → First matching element.  
- querySelectorAll() → All matching elements.

JavaScript DOM (Document Object Model)

The DOM (Document Object Model) is a way for JavaScript to interact with HTML. It treats an HTML page as a tree of objects where each tag (<h1>, <p>, <div>, etc.) is a node in the tree. Using the DOM, we can get, change, add, or remove elements.

1. DOM Structure


In the DOM, <html> is the root → inside it we have <body> → inside body we have <h1> and <p>.


Example HTML:

<html>
  <body>
    <h1 id="title">Hello</h1>
    <p class="text">This is a paragraph</p>
  </body>
</html>

5. Creating and Adding Elements

// Create a new paragraph
let newPara = document.createElement("p");
newPara.innerText = "This is a new paragraph!";

// Add it inside body
document.body.appendChild(newPara);

6. Removing Elements

let oldPara = document.querySelector(".text");
oldPara.remove();  // Removes the paragraph


Summary:  
- The DOM is a tree representation of HTML.  
- JavaScript uses the DOM to manipulate elements.  
- We can access, change, create, and remove elements with DOM methods.

JavaScript Event Listeners

An event is an action that happens on a web page (like a click, hover, key press, or form submit). With addEventListener(), we can tell JavaScript to run some code when an event occurs.

1. Basic Example: Click Event

// HTML
<button id="btn">Click Me</button>

// JavaScript
let button = document.getElementById("btn");

button.addEventListener("click", function() {
  alert("Button was clicked!");
});

2. Mouse Events

// HTML

Hover over me!

// JavaScript
let para = document.getElementById("para");

para.addEventListener("mouseover", function() {
  para.style.color = "red";   // Change color on hover
});

para.addEventListener("mouseout", function() {
  para.style.color = "black"; // Back to black when mouse leaves
});

3. Keyboard Event

// HTML
<input type="text" id="inputBox" placeholder="Type something">

// JavaScript
let input = document.getElementById("inputBox");

input.addEventListener("keydown", function(event) {
  console.log("Key pressed: " + event.key);
});

4. Multiple Events on Same Element

let box = document.getElementById("btn");

box.addEventListener("mouseenter", () => {
  console.log("Mouse entered button");
});

box.addEventListener("mouseleave", () => {
  console.log("Mouse left button");
});


Summary:  
- addEventListener("event", function) → Attaches a function to run when the event happens.  
- Common events: click, mouseover, mouseout, keydown, submit.  
- Use removeEventListener() to stop an event from listening.

JavaScript Conditional Statements

Conditional statements are used to make decisions in code. They allow JavaScript to run different blocks of code based on certain conditions.

1. if Statement

// Example 1
let age = 18;

if (age >= 18) {
  console.log("You are an adult");
}
- `let age = 18;` → Variable `age` ko 18 assign kiya.  
- `if (age >= 18)` → Condition check: "kya age 18 ya usse zyada hai?"  
- If condition `true` hai → `"You are an adult"` print hoga.  
- If condition `false` hoti → kuch bhi run nahi hota.

2. if...else Statement

let marks = 40;

if (marks >= 50) {
  console.log("Pass");
} else {
  console.log("Fail");
}
- Agar `marks >= 50` → `"Pass"` print karega.  
- Agar condition false hai → `"Fail"` print karega.

3. if...else if...else Statement

let percentage = 75;

if (percentage >= 80) {
  console.log("Grade A+");
} else if (percentage >= 60) {
  console.log("Grade B");
} else {
  console.log("Grade C");
}
- Agar `percentage >= 80` → `"Grade A+"`.  
- Agar pehli condition false hai lekin `percentage >= 60` true hai → `"Grade B"`.  
- Agar dono conditions false → `"Grade C"`.

4. Nested if (if ke andar if)

let user = "student";
let marks = 85;

if (user === "student") {
  if (marks > 80) {
    console.log("Excellent Student");
  }
}
- Pehle check hoga → `user === "student"`.  
- Agar true hai → phir andar wala `if` check karega `marks > 80`.  
- Agar dono true → `"Excellent Student"` print hoga.

JavaScript Loops

Loops are used when we want to repeat a block of code multiple times. Instead of writing the same code again and again, we can use a loop.

1. for Loop


The for loop repeats code a fixed number of times.


for (let i = 1; i <= 5; i++) {
  console.log("Number: " + i);
}
- `let i = 1;` → loop start hoga i = 1 se  
- `i <= 5;` → loop chalega jab tak condition true hai  
- `i++` → har round ke baad i ko 1 se increase karega  
- Output: 1, 2, 3, 4, 5

2. while Loop


The while loop keeps running as long as the condition is true.

let x = 1;

while (x <= 3) {
  console.log("Count: " + x);
  x++;
}
- Pehle condition check hoti hai `x <= 3`  
- Agar true → block chalega  
- Har round mein x++ hota hai

3. do...while Loop


This loop runs the code at least once, even if condition is false.

let y = 6;

do {
  console.log("Value: " + y);
  y++;
} while (y <= 5);
- Code ek dafa run hoga chahe condition false ho  
- Yahan pe `y=6` hai, condition false hai lekin output ek dafa print hoga

4. for...of Loop (Arrays)


The for...of loop is used to go through arrays.

let fruits = ["Apple", "Banana", "Mango"];

for (let fruit of fruits) {
  console.log(fruit);
}
**Output:**  
Apple  
Banana  
Mango

5. forEach() Method (Arrays)


The forEach() method runs a function for each array element.

let numbers = [10, 20, 30];

numbers.forEach(function(num) {
  console.log(num);
});
**Output:**  
10  
20  
30  


Summary:  
- for → Use when you know how many times to repeat.  
- while → Keep running while condition is true.  
- do...while → Run at least once, then check condition.  
- for...of → Best for looping through arrays.  
- forEach() → Array method for looping.

JavaScript Array Methods

Arrays are used to store multiple values in a single variable. Some important methods to add or remove items in arrays are:

1. push()


Adds an item at the end of the array.

let fruits = ["Apple", "Banana"];
fruits.push("Mango");

console.log(fruits); 
// Output: ["Apple", "Banana", "Mango"]

2. pop()


Removes the last item from the array.

let fruits = ["Apple", "Banana", "Mango"];
fruits.pop();

console.log(fruits); 
// Output: ["Apple", "Banana"]

3. shift()


Removes the first item from the array.

let fruits = ["Apple", "Banana", "Mango"];
fruits.shift();

console.log(fruits); 
// Output: ["Banana", "Mango"]

4. unshift()


Adds an item at the start of the array.

let fruits = ["Banana", "Mango"];
fruits.unshift("Apple");

console.log(fruits); 
// Output: ["Apple", "Banana", "Mango"]

Bootstrap Breakpoints

Breakpoints are specific screen widths where Bootstrap changes the layout to make websites responsive (mobile-friendly).

Bootstrap Default Breakpoints
- Extra Small (xs): <576px  → class is just .col
- Small (sm): ≥576px → class is .col-sm
- Medium (md): ≥768px → class is .col-md
- Large (lg): ≥992px → class is .col-lg
- Extra Large (xl): ≥1200px → class is .col-xl
- Extra Extra Large (xxl): ≥1400px → class is .col-xxl

Usage Example
<div class="container">
  <div class="row">
    <div class="col-12 col-sm-6 col-md-4 col-lg-3" 
         style="background:lightblue">
      Responsive Column
    </div>
    <div class="col-12 col-sm-6 col-md-8 col-lg-9" 
         style="background:lightgreen">
      Another Column
    </div>
  </div>
</div>
Breakpoints let you design layouts that look good on 
MOBILE 📱, TABLET 💻, and DESKTOP 🖥️ devices.

Container vs. Container-Fluid

✔ container - Fixed width (changes at breakpoints). - Content is centered with margins on left and right. ✔ container-fluid - Full width of the screen (always 100% width). - Used when you want your layout to span the entire page.

<div class="container">
  <p>This is inside a fixed container.</p>

<div class="container-fluid">

</div>

Mini Project Bootstrap + jQuery

Note

This project has been built using Bootstrap and jQuery together. To keep things simple, we are providing a single downloadable ZIP file that contains the complete mini project.

Setup jQuery

Before you can use jQuery, you need to include its library in your project. You can do this easily using a CDN (Content Delivery Network).

 Add inside  or just before closing <script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>

Document Ready

jQuery provides a special function $(document).ready() which ensures that your code runs only after the HTML page is fully loaded. Why Important? If you try to run jQuery before the page is ready, it may not find the elements you are trying to manipulate.

<script>
  $(document).ready(function() {
    alert("Page is fully loaded and ready!");
  });</script>

Selectors & CSS Manipulation

jQuery selectors are very powerful. They allow you to pick elements just like CSS does:$("p") → selects all tags ,$("#id") → selects an element with a specific ID , $(".class") → selects all elements with a class.Once selected, you can change their style dynamically using .css().

<p>This is a paragraph</p>
<button id="styleBtn">Change Style<button>

<script>
  $(document).ready(function() {
    $("#styleBtn").click(function() {
      $("p").css("color", "blue"); // change text color to blue
    });
  });
</script>

Hide and Show Elements

Sometimes you may want to temporarily hide an element and later show it again. jQuery provides .hide() and .show() methods for this.

<p>I can be hidden or shown!</p>
<button id="hideBtn">Hide</button>
<button id="showBtn">Show</button>

<script>
  $(document).ready(function() {
    $("#hideBtn").click(function() {
      $("p").hide(); // hides paragraph
    });
    $("#showBtn").click(function() {
      $("p").show(); // shows paragraph
    });
  });
</script>

Toggle Elements

If you don't want two separate buttons (hide/show), you can use .toggle(). It will automatically switch between visible and hidden.

<p>Click the button to toggle me!</p>
<button id="toggleBtn">Toggle</button>

<script>
  $(document).ready(function() {
    $("#toggleBtn").click(function() {
      $("p").toggle();
    });
  });
</script>

jQuery Events

Events are actions performed by the user (clicking, typing, hovering, etc.). In jQuery, you attach event handlers easily:

  • .click() → runs when element is clicked
  • .dblclick() → runs when element is double clicked
  • .hover() → runs when mouse enters/leaves an element

<script>
  <button id="clickMe">Click Me</button>

  $(document).ready(function() {
    $("#clickMe").click(function() {
      alert("Button was clicked!");
    });
  });

</script>

Animate Elements

jQuery can create simple animations with .animate(). You can smoothly change CSS properties like size, position, or opacity over time.

<div id="box" style="width:100px;height:100px;background:red;position:relative;"></div>
<button id="moveBtn">Move Box</button>

<script>
  $(document).ready(function() {
    $("#moveBtn").click(function() {
      $("#box").animate(
        { left: '250px', opacity: 0.5 }, // properties to animate
        1000 // duration in milliseconds
      );
    });
  });
</script>
